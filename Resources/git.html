Git Cheat Sheet

Setup & Configuration

git config --global user.name "[name]"
Set your name for commits
git config --global user.email "[email]"
Set your email for commits
git config --global color.ui auto
Enable colorized output
git init
Initialize a new Git repository
git clone [url]
Clone a repository from URL

Stage & Snapshot

git status
Show modified files in working directory
git add [file]
Add a file to staging area
git add .
Add all files to staging area
git reset [file]
Unstage a file while keeping changes
git diff
Show changes not yet staged
git diff --staged
Show changes staged but not committed
git commit -m "[message]"
Commit staged changes with message
git commit -am "[message]"
Add all tracked files and commit

Branch & Merge

git branch
List all branches (* = current)
git branch [branch-name]
Create a new branch
git checkout [branch]
Switch to another branch
git checkout -b [branch]
Create and switch to new branch
git checkout -b [branch] origin/[branch]
Clone remote branch and switch to it
git merge [branch]
Merge specified branch into current
git branch -d [branch]
Delete a branch (safe)
git branch -D [branch]
Force delete a branch

Remote & Sync

git remote add [alias] [url]
Add a Git URL as an alias
git remote -v
Show remote repositories
git fetch [alias]
Fetch all branches from remote
git pull
Fetch and merge remote changes
git push [alias] [branch]
Push local branch to remote
git push -u origin [branch]
Publish new branch to remote
git push --force
Force push (can overwrite remote history)
git push --tags
Push all tags to remote
git branch --merged git push origin --delete [branch-name]
Delete remote branch after merging (check it's well merged in main though)

History & Revert

git log
Show commit history
git log --oneline
Show compact commit history
git log --graph
Show branch graph
git revert [commit]
Create new commit that undoes changes
git reset --soft [commit]
Reset to commit, keep changes staged
git reset --hard [commit]
Reset to commit, discard all changes
git rebase [branch]
Apply current branch commits ahead of specified branch
git rebase -i [commit]
Interactive rebase (can rewrite history)

Inspect & Compare

git show [commit]
Show details of a specific commit
git diff [branch1]..[branch2]
Show differences between branches
git log [branch1]..[branch2]
Show commits on branch2 not on branch1
git log --follow [file]
Show commits that changed file
git blame [file]
Show who changed each line

Temporary Storage

git stash
Save modified and staged changes
git stash save "[message]"
Save stash with custom message
git stash list
List all stashes
git stash pop
Apply and remove latest stash
git stash apply
Apply latest stash without removing
git stash drop
Delete latest stash

File Operations

git rm [file]
Remove file from project and stage removal
git rm --cached [file]
Remove from tracking but keep locally
git mv [old-path] [new-path]
Move/rename file and stage the move
git log --stat -M
Show commit logs with moved files

Ignore Patterns

git check-ignore [file]
Check if file is ignored
.gitignore examples: 
# Ignore all .o files
*.o

# Ignore all files named foo.txt
foo.txt

# Ignore all files in the build/ directory
build/

# Ignore all .log files in any directory
*.log

# Ignore a specific file even if it's in a directory that's ignored
!/my_ignored_dir/keep_this_file.txt
